# Harness · Consultora

Loop orientado a **cliente de TI**:

1. Discovery / briefing (PO)
2. Plan + wireframes + diagrama (aprobación humana)
3. Sprint execution (especialistas + coding adapter)
4. Verifier separado
5. Entrega con capturas e informe
6. Feedback humano obligatorio

**Stop conditions:** criterios de aceptación del sprint o rechazo del usuario.
**State:** `.agency/sprints/`, `artifacts/`, `handoffs/`.
