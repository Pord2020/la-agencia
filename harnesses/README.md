# Harnesses

Un **harness** define cómo corre el trabajo alrededor del modelo: tools, verificación, recuperación, parada.

| ID | Estado |
| --- | --- |
| `consultancy` | Implementado en v0.4: sprints, artefactos y feedback humano |
| `ralph-loop` | Catálogo/roadmap; no ejecutable |
| `generator-evaluator` | Catálogo/roadmap; no ejecutable |
| `long-running` | Catálogo/roadmap; no ejecutable |
| `multi-office` | Catálogo/roadmap; no ejecutable |

La v0.4 no permite elegir un harness no implementado. Los manifiestos de roadmap
sirven para diseño y contribución, no como afirmación de capacidad actual.
