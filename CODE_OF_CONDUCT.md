# Código de conducta

Este proyecto adopta el [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Esperamos colaboración respetuosa, inclusiva y centrada en el trabajo. No se
toleran acoso, ataques personales, divulgación de información privada ni
conductas que pongan en riesgo a usuarios no técnicos.

Los incidentes confidenciales se reportarán a los maintainers mediante el canal
privado del repositorio. Los maintainers podrán advertir, moderar, suspender o
excluir participantes de forma proporcional y documentada.

## English

This project adopts [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
We expect respectful, inclusive and work-focused collaboration. Harassment,
personal attacks, disclosure of private information and conduct that endangers
non-technical users are not accepted. Confidential incidents must use the
repository's private maintainer channel. Enforcement is proportional and
documented.
