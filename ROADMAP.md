# Roadmap

## Now — v0.4

Runtime local seguro, permisos bloqueantes, operaciones persistentes, QA con
evidencia, preview opt-in, tests, CI, sidecar experimental y biblioteca diaria
de recursos open source.

## Next — v0.5/v0.6

- v0.5: generator/evaluator, Ralph Loop, cost-aware y triggers manual/intervalo.
- v0.6: multi-office, MCP con permisos por herramienta, cron/webhooks y métricas.

## Later — v1.0

Graduar Desktop a estable después de firma/notarización, updater seguro y pruebas
de instalador soportadas en macOS, Windows y Linux. El sidecar, CSP e instancia
única ya existen en v0.4, pero el paquete continúa marcado como experimental.

## English

- v0.4: secure local runtime, blocking permissions, persistent operations,
  evidence-backed QA, opt-in previews, CI and a safely acquired resource index.
- v0.5: real generator/evaluator and Ralph loops, cost awareness and manual or
  interval triggers.
- v0.6: multi-office routing, per-tool MCP permissions, cron/webhooks and
  observability.
- v1.0: graduate Desktop only after signing/notarization, a secure updater and
  supported installer tests on macOS, Windows and Linux.
