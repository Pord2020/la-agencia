# Soporte

- Bugs reproducibles: issue usando la plantilla de bug.
- Ideas: issue de feature o Discussions cuando esté habilitado.
- Vulnerabilidades: canal privado descrito en `SECURITY.md`.
- Preguntas de terceros (Claude, Codex, Cursor, etc.): soporte del proveedor.

Incluye sistema operativo, versión de Node, adapter, logs redactados y pasos de
reproducción. Nunca adjuntes tokens, API keys o el contenido de tu HOME.

## English

Use the bug template for reproducible defects and the feature template or
Discussions for ideas. Security reports use the private channel in
`SECURITY.md`; provider-specific account issues belong with that provider.
Include OS, Node version, adapter, redacted logs and reproduction steps. Never
attach tokens, API keys or HOME-directory content.
