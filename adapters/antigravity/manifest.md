# Adapter · Antigravity

Viable como executor agent-first de Google (`agy` CLI).

- Detect: `agy` en PATH
- Auth: login Google / plan Antigravity
- Run: headless `agy -p "..."` (con flags de permisos según docs)
- Uso típico: tareas bulk baratas (orquestador cost-aware)
- Oficina UI: **Antigravity**
- Docs: https://antigravity.google/
