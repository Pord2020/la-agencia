# apps/server · Agency Runtime

Runtime local:

- API Hono protegida por sesión local y origen estricto
- Operaciones, permisos y cola persistente con recuperación
- Flujo `consultancy + po-techlead`
- Adapter autónomo Codex y detección honesta de adapters manuales
- Workspace staging, verificación separada y ledger de uso
- Previews locales y túneles públicos con consentimiento individual

Arranque: `npm run agency` desde la raíz. La app Desktop usa el mismo runtime
como sidecar autocontenido.
