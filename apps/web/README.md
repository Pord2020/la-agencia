# apps/web · Oficina local

La interfaz v0.4 ofrece un único flujo visible y verificable:

- onboarding bilingüe ES/EN;
- oficina `consultancy + po-techlead`;
- proyectos, sprints, permisos y operaciones persistentes;
- biblioteca de agentes/skills con adquisición explícita;
- previews locales y acción separada para compartir públicamente.

Las oficinas multi-adapter, MCP y otros harnesses permanecen ocultos hasta que
dispongan de runtime y pruebas reales.
