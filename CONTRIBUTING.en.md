# Contributing

Read `docs/CODE_STYLE.md`, `docs/ARCHITECTURE.md`, and `docs/TESTING.md` before
changing runtime behavior.

```bash
npm install
npm run check
git commit -s
```

Pull requests must explain what changed, why, how it was tested, and any
remaining risk. UI changes include screenshots. Security-sensitive changes
must not weaken permission, workspace, secret, or network boundaries.

The DCO sign-off certifies that you have the right to contribute the work under
MIT. Source code and technical JSDoc use English; user-facing text supports
Spanish and English.
